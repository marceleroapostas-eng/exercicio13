\# Exercício 13 - Empréstimo



\## Descrição



Este programa solicita o salário bruto e o valor da prestação de um empréstimo. Em seguida, verifica se o valor da prestação é de até 30% do salário para determinar se o empréstimo pode ser concedido.



\## Tecnologias utilizadas



\- Java

\- NetBeans

\- Maven



\## Entrada



A entrada contém o salário bruto e o valor da prestação do empréstimo, informados pelo usuário.



\## Saída



O programa informa se o empréstimo pode ou não ser concedido, considerando o limite de 30% do salário.
